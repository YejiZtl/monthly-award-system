## 已实现能力

- 免登录申报：项目负责人自由填写、选填、可为空；主材料接收 XLSX、PNG、JPG，证明附件接收 PNG、JPG。
- 原件固化：扩展名、MIME、文件头、10MB/30文件限制、SHA-256 去重、批次隔离和原件在线查看。
- 本地识别：XLSX 直接提取；Excel 截图经过方向、尺寸、灰度、对比度和锐化预处理后由 RapidOCR 识别，无法确认的字段进入人工核对。
- 字段核对：revision 防并发覆盖，关键字段必须人工确认；送审后不能再由员工修改。
- 权威核算：后端从已确认字段快照生成输入，忽略客户端提交的金额；全程 Decimal，按工程文档规则计算和舍入。
- 单人审核：审核令牌、退回、确认、金额覆盖原因必填、修改前后值与操作者审计。
- 正式导出：只读复制 51 页官方模板，生成公式版/数值版、项目成本、计算过程、识别结果、异常、来源和审计页；导出版本不覆盖并记录 SHA-256。
- 管理与运维：管理员口令/HMAC 会话、管理员批次删除、系统设置、带时效签名的下载链接、SQLite WAL、独立 worker、每日备份和恢复工具。

## 当前本机预览

前端页面：

http://127.0.0.1:4173/preview/

后端已启动时，页面右上角显示“后端已连接”。API 健康检查和文档：

- http://127.0.0.1:8000/health
- http://127.0.0.1:8000/docs

管理员批次管理位于审核端“系统状态”。本机使用前在 `.env` 配置 `ADMIN_PASSWORD` 和 `ADMIN_SESSION_SECRET`，重启后端后即可登录并删除批次。

## 本机开发启动

首次安装：

~~~powershell
py -3.12 -m venv backend\.venv
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
~~~

启动后端：

~~~powershell
$env:PYTHONPATH='backend'
backend\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
~~~

如需重新启动静态预览：

~~~powershell
python -m http.server 4173 --directory frontend
~~~

## Docker Compose 局域网启动

~~~powershell
Copy-Item .env.example .env
docker compose up --build -d
~~~

Compose 会启动 Web、FastAPI、独立识别 worker 和每日备份服务。生产模式必须在 **.env** 设置 **REVIEWER_TOKEN**、**ADMIN_PASSWORD**、**ADMIN_SESSION_SECRET**。默认图片识别只需填写 **ZAI_API_KEY**；旧 `LLM_API_KEY` 在 `LLM_PROVIDER=bigmodel` 时不会读取或发送。
生产模式下，审核人点击页面右上角账号区域输入审核令牌；令牌只保存在当前浏览器标签页会话中。

## 集团局域网部署

不需要域名或公网端口。服务器连接集团网络后，可用原生 Windows 运行方式把页面与 API 统一开放在局域网端口 `8000`，Windows 防火墙规则只允许本地子网访问。

完整启动、验证和停止步骤见 [局域网部署说明](docs/LAN_DEPLOYMENT.md)。

需要把项目交给服务器管理员部署时，请使用 [部署交接说明](docs/DEPLOYMENT_HANDOFF.md)。

图片模型配置后，可用不含真实业务数据的合成表单检查接口、模型和结构化返回：

~~~powershell
backend\.venv\Scripts\python.exe infra\llm_probe.py
~~~

探针只输出模型名、字段结果和安全错误码，不输出模型地址或密钥。

## 自动测试

~~~powershell
$env:PYTHONPATH='backend'
backend\.venv\Scripts\python.exe -m unittest discover -s backend\tests -v
~~~

当前使用 pytest 运行全部95项测试（另含5个子测试），覆盖八类标准模板及旧版流程。安装 `backend/requirements-test.txt` 后设置 `PYTHONPATH=backend`，运行 `python -m pytest backend/tests -q`。原 unittest 命令仍可运行兼容测试，但不会收集全部新增测试。

每日备份服务默认保存数据库、原件和导出文件，并保留最近7个版本。手工备份/离线恢复方法见 [备份与恢复说明](docs/BACKUP_AND_RESTORE.md)。

## 业务安全边界

- 员工只能修正确认字段，不能选择其他规则或直接控制奖金。
- 毛利超过50万元只计算已确认区间，超过部分不推断，必须由审核人确认。
- EFP正式服务费标准未最终确认前，只采用部门提交并经审核人确认的金额。
- 不接收发票、税务票据或财务报销凭证。
- 图片接口密钥只进入服务器环境变量，不写入前端、数据库、导出文件或日志。

## 上线前仍需外部条件

- 使用服务器侧真实图片模型配置和脱敏图片做接口探针。
- 按业务要求完成每类至少10份、合计不少于50份脱敏材料验收。
- 正式局域网部署时配置 HTTPS、强口令和服务器备份目录；如并发规模扩大，再从当前单机 SQLite 迁移 PostgreSQL。
