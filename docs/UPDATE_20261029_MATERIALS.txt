员工月奖系统 0.7.6 更新说明（2026-10-29）

本次修改
1. 导出ZIP中，materials下的目录优先使用项目名称；未填写项目名称时使用表单名称，增补材料使用增补名称。不再使用item-001等编号目录。
2. 文件名中的特殊字符自动替换；重名目录增加（2）、（3）等后缀，避免解压覆盖。汇总表和本地HTML目录中的材料链接同步更新。
3. 初审退回提交员工后，员工“工作台”入口右侧显示待修改表单数量，例如1。记录显示“初审退回 · 待修改”和退回原因，可继续核对。
4. 重新提交后相应减少数字；查看、刷新或关闭重开页面不会提前消除提醒。其他月份尚未修改完的退回表单也显示在记录中。
5. 页面打开时每15秒自动更新，切回窗口时也刷新。保持原有本机员工隔离，其他员工看不到该材料和提醒。
6. 复审退初审沿用初审数字提醒，不误发给员工。原有0.7.5功能均包含在更新包内。

公司Mac一键更新
将“员工月奖系统_材料命名及退回提醒更新包_0.7.6_20261029.zip”放到Mac桌面。
在无人申报的时段，于Mac终端复制执行以下整段：

scp "$HOME/Desktop/员工月奖系统_材料命名及退回提醒更新包_0.7.6_20261029.zip" awardadmin@<SERVER_IP>:~/monthly-award-update-076.zip && \
ssh -t awardadmin@<SERVER_IP> 'set -e; stage=$(mktemp -d "$HOME/monthly-award-update-076.XXXXXX"); /opt/monthly-award/.venv/bin/python -m zipfile -e "$HOME/monthly-award-update-076.zip" "$stage"; cd "$stage/员工月奖系统"; sudo bash infra/upgrade_vm_update_20261029_materials.sh'

脚本会先校验并备份程序、配置和数据库，再更新服务并检查版本0.7.6。
升级后按Command+Shift+R强制刷新浏览器，员工入口显示为“工作台”。
本次未连接或更新公司虚拟机，需执行上述安装步骤。

验收
- 初审退回一份测试申报，原提交电脑的工作台显示1，并能看到退回原因；刷新页面后数字仍保留。
- 修改并重新提交后数字消失；复审退初审只提醒初审，员工端不显示退回提醒。
- 对含项目表、固定表单和增补条目的月份重新导出，完整解压后检查中文目录名和材料链接。

范围
更新包不包含业务数据库、上传材料或账号口令，保留现有运行数据。
已下载的旧归档不会自动改名，需要重新导出。
