# 2026年10月月奖系统更新说明

本次更新依据用户提供的修改清单、新版核算表和证明材料模板。核算表中的已填金额、项目、人员和余额均作为示例，不导入生产数据库，不作为本月应发额。下载的空白表清除申报示例；驾驶班 B—E 列的序号、车牌和车辆资料按要求保留。

## 已调整的使用流程

- 上传新版或已提供的历史布局时，按表格结构识别类型。选择的类型不匹配时提示确认后切换，无须重新选择文件。
- SONY维修同时支持 I 列及 J 列的毛利1、毛利2；音频后期支持新版40行设备租赁表、测试包26行设备表及旧版含毛利表。新版不再要求已删除的毛利字段。
- 下载音频空白表保留收费查找表、下拉菜单和公式，补齐40行工时与费用公式。驾驶班保留 B—E 列固定资料。
- 附件可逐张追加、单独移除；上传失败保留文件及批次，重试不会重复存入相同材料。单文件10MB、每批最多30个文件。
- 页面短时连接失败会自动重新检查，并提供“重试连接”。上传校验与文件处理移到服务线程，避免阻塞整个接口进程。Docker代理的请求总大小限制同步到30文件上限；标准虚拟机直接使用8000端口，不依赖该代理。
- 字段核对中“大屏技术服务费”排在 EFP 后面，提供“返回修改上传文件”；Excel“打开材料”进入保留合并单元格及主要格式的在线预览，下载作为独立操作。预览不执行公式，未缓存的公式明确提示，不能替代 Excel 编辑。
- 待审申报可“撤回修改”；旧审核页面不能再确认已撤回的计算。已审核或已导出申报可“创建修订申报”，上传完整新材料并再次审核。修订通过前原记录继续有效，通过后汇总只计新版；旧材料及历史导出保留。
- 员工页显示本浏览器创建的申报记录；清除浏览器数据或换设备后需由审核员查找原申报。审核员在“申报与核对”可处理已有记录。原系统仍采用免登录申报方式。
- 审核员和管理员密码提供显示/隐藏按钮。
- 汇总“查看表单和证明”先展示当时保存的 Excel 原件及证明；人工修改的核对字段可展开查看。
- 数值版的应发金额是审核时固定值；公式版的应发栏为分项合计加核定差额，保留审核金额缓存，修改分项后会重算。两版初次打开金额相同。其他、权重、实发留空。基础奖人数、样例余额及示例人员不自动计奖，需审核员按实际填写或核定。

## 在公司原虚拟机上更新

更新包适用于原标准安装路径 `/opt/monthly-award`、数据路径 `/var/lib/monthly-award` 及 `monthly-award` / `monthly-award-worker` 服务。此包是程序更新包，不是替换整台虚拟机的磁盘镜像。更新期间短暂停止服务，请选无正在申报的时间操作。

1. 先给现有虚拟机做快照。把更新 ZIP 复制到虚拟机，解压到一个独立目录，不要先覆盖 `/opt/monthly-award`。
2. 在解压后的 `员工月奖系统` 目录中运行：

```bash
sudo bash infra/upgrade_vm_20261019.sh
```

脚本先校验文件并备份程序与配置，再停止服务、备份数据库并更新程序。账号密码、原件和历史导出不会被更新包替换。脚本只调整标准模板路径，不打印配置中的密码或密钥。启动检查失败会恢复旧程序和配置；数据库只增加兼容旧程序的可空字段。

3. 看到“更新完成”后，在浏览器按 Ctrl+F5。用一份脱敏表和多张证明验证上传、字段核对、撤回、审核、修订、导出。
4. 若公司环境仍有间歇故障，在故障时间附近运行下面的只读诊断，将结果交给管理员。日志可能包含文件名称和业务错误，请在分享前检查内容。

```bash
sudo bash infra/diagnose_vm.sh > monthly-award-diagnostics.txt 2>&1
```

备份目录会在脚本输出中显示，形如 `/var/backups/monthly-award/update-20261019-时间`。需手动回退时，先停止两个服务，将该目录中的 `code.tar.gz` 解压回 `/opt/monthly-award`，将 `app.env` 复制回 `/etc/monthly-award/app.env`，再启动两个服务。回退前若已产生新业务数据，不要直接覆盖数据库；请由管理员决定是否从虚拟机快照或数据库备份恢复。

## 验证范围

本地使用隔离测试数据库，未连接或修改公司生产服务器。后端自动测试、前端针对性测试和提供的10份Excel上传测试均在本地执行；非编主表与3张证明已验证可上传、重试和预览。具体检查结果见同目录的 `VALIDATION_20261019.txt`。公司服务器的实际进程、磁盘、内存和网络情况需部署后再核实。
