# 实施状态（V0.3）

## 已完成

- P0 规则与模板：10 类确定性规则入口、工程文档黄金样例、51 页正式 Excel 母版、版本 manifest 和 SHA-256 已固化。
- P1 工程骨架：FastAPI、React/Vinext、SQLite WAL、Nginx、Docker Compose、健康检查、环境变量和局域网部署结构。
- P2 上传与识别：JPG/PNG/XLSX 校验、隔离存储、原子去重、异步任务表、独立 worker、XLSX 提取、图片方向/尺寸预处理与清晰度增强、10 类表格专用字段提示词、智谱免费 `glm-4.6v-flash` 专用请求、整图抽取后对缺失/低置信度字段定向复核、跨轮候选合并、OpenAI 兼容参数自动降级、服务端归一化、接口运行状态和带原因的人工回退。
- P3 核算与审核：字段 revision、关键字段确认、证据状态约束、服务端权威输入快照、Decimal 规则引擎、单一审核人、金额覆盖原因和审计事件。
- P4 正式导出：母版只读复制、历史项目数据清理、公式版/数值版、内部链接、项目成本、计算过程、识别结果、异常、来源、审计、SHA-256 和时效签名下载。
- P5 本机加固：审核令牌、管理员会话、系统设置、SQLite 安全备份、离线恢复前安全备份、7个日版本保留和容器健康检查。

## 验证结果

- 后端 40 项自动测试全部通过，其中 10 项覆盖智谱免费模型端点、参数与公共模型目录差异、通用视觉模型正常识别、图片缩放与增强、返回值归一化、低置信度定向复核、跨轮候选合并、无效 JSON 重试、OpenAI 可选参数兼容回退、缺字段人工占位、运行状态和鉴权错误脱敏。
- API 集成链路通过：创建批次 → 上传 → 异步识别 → 字段确认 → 校验 → 核算 → 审核 → 导出 → 签名下载。
- 已验证客户端篡改核算输入不会影响奖金，后端只使用已确认字段快照。
- 正式母版公式版和数值版回归通过；原 51 页保留，新增6个审计页，母版 SHA-256 不变。
- 57 个导出页均完成渲染检查，未发现 REF、DIV/0、VALUE、NAME 或 N/A 公式错误。
- 前端生产构建与 ESLint 通过；预览页已确认显示“后端已连接”，浏览器控制台无错误。
- 备份/恢复演练通过：数据库完整性、原件和导出文件均能恢复。

## 需要部署方提供或确认

- 图片模型：在服务器侧填写 `ZAI_API_KEY`，并用脱敏图片完成智谱免费模型实际接口探针。
- 生产凭据：设置 REVIEWER_TOKEN、ADMIN_PASSWORD、ADMIN_SESSION_SECRET。
- 网络上线：配置局域网 HTTPS、服务器地址、备份卷落盘位置和磁盘告警。
- 业务验收：每类至少10份、总计不少于50份脱敏材料；关键金额人工复核准确率目标不低于98%。
- 数据库演进：当前符合单审核人本机试运行的 SQLite 路线；并发规模或组织范围扩大时再迁移 PostgreSQL/Alembic。

## 暂不自动发布的业务口径

- 毛利超过50万元时只计算50万元以内参考值，超过部分由办公会议/审核人确定。
- EFP技术服务费标准未最终确认时，只使用员工提交并经审核人确认的金额。
- 预算转决算跨月差额只保存版本和审计，不擅自跨月入账。
