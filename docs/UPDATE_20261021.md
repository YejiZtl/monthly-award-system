# 2026年10月21日更新说明

本次按10月20日的9项修改意见更新，版本为0.6.0。终审沿用现有审核员权限。

## 使用变化

1. 上传毛利、毛利1、毛利2按四舍五入取整数。例如7251.66371681416显示并核算为7252；原始读取值仍保留。已审核记录不会自动重算，需重新申报或修订后再审核。
2. 撤回后的字段核对页提供“返回上传”，可回到首页重新选择主表及附件。确认返回后清除该未审核批次的旧材料，需重新上传完整材料。
3. 工作台、申报记录和审核列表在表格类型后显示表内项目名称，终审池也显示项目名称。
4. Excel在线预览遵守隐藏行列，包括音频后期用一个分组隐藏的A、B两列；合并单元格跨越隐藏列时仍正常显示。原件中的查找表、下拉菜单及公式保留。
5. 材料和证明提供独立的“直接打开”及“下载原文件”入口。
6. 同月同部门或同名项目已存在有效审核记录时，审核新表会提示确认替换。确认后本月汇总只计新表，旧原件和已生成历史文件保留。也可在终审池点击“替换申报材料”创建修订申报，上传完整新材料重新审核。
7. 音频后期汇总备注移除“旧版含毛利时按超额累进核算。”，已保存备注读取时也去除该句。兼容旧表的计算规则不因此改变。
8. 单表审核通过后进入“终审与导出”的终审池。按结算月份汇总，默认当前月份；可切换处理补报月份。终审前可查看材料、调整金额并填写原因、修改汇总备注或替换申报。点击“终审并归档公式版/数值版”并确认后，才生成历史文件。金额调整生成新的核算快照，历史版本的金额和文件保持原样。两种格式分别终审归档；若期间有人修改或替换内容，系统要求刷新重新核对。
9. 附件逐个上传，显示文件进度，单文件最多等待120秒。网络中断或服务器临时错误自动重试一次；手动重试时跳过本次页面会话中已成功上传的文件，服务端仍按内容去重。刷新页面后重新选择文件可由服务端去重，上传进度不跨浏览器会话保存。单文件10MB、每批最多30个文件的限制保持不变。

## 更新公司虚拟机

适用于原标准安装路径 `/opt/monthly-award` 和原 `monthly-award`、`monthly-award-worker` 服务。本包包含前次更新的程序与标准模板，可从此前标准版本更新。

1. 在无正在申报的时段更新，并先给虚拟机做快照。
2. 将更新ZIP解压到独立目录，不要提前覆盖现有程序。
3. 进入解压后的“员工月奖系统”目录，运行：

```bash
sudo bash infra/upgrade_vm_20261021.sh
```

4. 看到“更新完成”后，所有使用者在浏览器按Ctrl+F5，确保前后端同时使用新版本。旧页面不能绕过终审直接导出，会提示刷新。
5. 用测试申报核验：打开音频表不显示A、B列；撤回后返回上传；新表替换；修改终审金额；分别归档数值版与公式版。

脚本校验文件、备份程序/配置/数据库后再更新，保留原账号密码、上传材料和历史文件。启动检查失败会恢复程序与配置。备份位于 `/var/backups/monthly-award/update-20261021-时间`。需要回退时按上次更新说明恢复程序与配置；产生新业务数据后不要直接用旧数据库覆盖。

## 验证与限制

本地使用隔离测试数据库。自动测试检查隐藏列与合并单元格、金额取整、替换限制、终审权限、终审期间修改的冲突保护、历史文件不变、逐文件上传和失败重试。测试结果见 `VALIDATION_20261021.txt`。

未连接或部署公司服务器，也未测量公司网络下的实际上传速度。此次改善了上传重试和超时处理；如部署后仍慢，应结合服务器诊断与实际网络继续定位。Excel在线预览仍使用保存的公式结果，不执行工作簿公式；缺少缓存时提示在Excel计算保存后重传。
