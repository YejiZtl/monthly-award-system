员工月奖系统 0.7.7 更新说明（2026-10-29）

本次修改
1. 员工工作台及审核端工作台、初审、复审、终审、导出页面每15秒自动同步业务数据，无需手动刷新整个网页。
2. 切回浏览器窗口或标签页时自动同步。后台不可见的页面暂缓请求，返回后继续。
3. 自动同步包括新申报、退回提醒、初审/复审待办数字、审核状态、空闲审核详情中的已保存意见、终审金额及备注、导出历史。
4. 正在输入、填写人工金额或未保存备注、打开修改弹窗、上传或保存数据时，暂缓自动同步，避免覆盖输入。离开输入框并保存完成后恢复。
5. 他人已处理的申报自动移出待审列表；本地存在未保存修改时保留输入，提交时仍由服务器校验状态及版本，防止互相覆盖。
6. 网络暂时失败时保留上次成功显示的数据，下次继续重试。连续请求不重叠，过期响应不覆盖后来的操作。
7. 包含0.7.6的材料目录命名、初审退回员工数字提醒及此前更新。

公司Mac一键更新
将“员工月奖系统_多人自动同步更新包_0.7.7_20261029.zip”放到Mac桌面。
在无人申报的时段，于Mac终端复制执行以下整段：

scp "$HOME/Desktop/员工月奖系统_多人自动同步更新包_0.7.7_20261029.zip" awardadmin@<SERVER_IP>:~/monthly-award-update-077.zip && \
ssh -t awardadmin@<SERVER_IP> 'set -e; stage=$(mktemp -d "$HOME/monthly-award-update-077.XXXXXX"); /opt/monthly-award/.venv/bin/python -m zipfile -e "$HOME/monthly-award-update-077.zip" "$stage"; cd "$stage/员工月奖系统"; sudo bash infra/upgrade_vm_update_20261029_sync.sh'

脚本先校验、备份程序配置和数据库，再更新并检查版本0.7.7。
升级后两台电脑均按Command+Shift+R强制刷新一次，以载入新版页面程序；之后业务变化自动同步。
系统管理页面的管理批次操作仍可使用原有手动刷新入口。

验收
- 两台电脑打开同一系统，第一台提交或审核，第二台停在工作台或待审列表，约15秒内看到状态和数字更新。
- 第二台打开审核详情并保持空闲，第一台保存审核意见，第二台无需刷新即可看到新意见。
- 第二台填写人工金额、备注或打开会议数据弹窗，第一台修改其他内容；第二台输入应保留，保存并离开输入框后继续同步。
- 第一台修改终审金额或备注，空闲的第二台终审页面自动显示新金额和备注。

范围
更新包仅含程序、模板和说明，不包含业务数据库、上传原件或账号口令。
本次仅在本机验证，未连接或更新公司虚拟机，需执行上述安装步骤。
