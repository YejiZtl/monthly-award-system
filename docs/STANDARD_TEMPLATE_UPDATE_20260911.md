# 2026-09-11 标准模板更新

本包是应用程序更新包，不是重新制作的 VMware 虚拟机。原始《制作中心月奖核算表.xlsx》保持不变，新模板已完整复制进应用目录，保留项目属性和税率单选控件。

## 员工申报

选择 I、K、L、M、N、O、1、2 对应的八种标准表格之一。点击“下载标准模板”只下载该表单的独立空白工作簿，填写后上传。2026-09-12 已将下载表拆分并清除示例姓名、项目、日期、业务金额和填写备注，保留收费标准、公式、下拉选项和项目属性/税率控件。汇总母版及非蓝底固定内容不受下载空表处理影响。

每次申报使用一份 XLSX 主表。证明图片可多份上传。读取到的金额须人工核对后送审；Excel 公式没有保存计算结果时，字段留空并要求补充，不猜测数值。建议填写后用 Excel/WPS 重新计算并保存。

采用上传合计计奖。2 表按人员、天数、单价复核明细，并核对有标准价格的服务行；差异会提示审核员，不静默覆盖上传合计。示例数据不作为当月默认数据。

## 审核与导出

- 汇总采用原表 B:N 格式，非蓝底固定内容保留；I 权重和 J 实发留空，供办公会议填写。
- 蓝底部门没有已审核申报时金额留空，不自动生成基础奖。
- 每个已审核项目增加一行，支持每月 40 项以上。
- 1 表按上传毛利累进奖励加设备、EFP、大屏奖励；2 表采用技术服务与设备奖励。同月同名项目或同部门重复申报在确认时提示，避免重复计奖。
- L 证明链接无需登录，持链接者可查看已填写字段、原表预览及全部证明，并下载原件。系统须运行且访问者能连到导出时所用地址；它不是离线附件。原件仍遵循系统保留/删除流程。
- 审核中心可编辑本条目“汇总表备注”；导出记录中的“汇总表备注”可按月编辑所有固定行和项目。修改留有记录，冲突时要求刷新。重新导出产生新文件，历史文件不会被覆盖。
- 旧批次保留，不自动推算成新模板。若一个月份混有旧版与新版已审核申报，导出会提示处理旧版，防止漏报或套错规则。

## 更新到已有安装

先备份现有程序、数据库与原件。应用更新包不含 `.env`、数据库、上传材料、历史导出或个人口令；保留服务器上的这些文件和目录。

将包内“员工月奖系统”应用文件更新到现有应用目录。原生运行方式需重新启动后台服务与识别 worker；Docker 方式在现有应用目录执行 `docker compose up --build -d`，同时重建 web、backend、worker。新增备注表在启动时自动建立，不清空既有业务数据。

Docker 已增加 `STANDARD_TEMPLATE_PATH`，并保留访问端口生成证明链接。若使用自定义部署，令此环境变量指向 `templates/excel/monthly_award_standard_2026_09.xlsx`。在局域网地址访问系统后导出，其他员工才能使用相同地址打开证明。

此次已更新本地应用源文件与更新包，未替换已有虚拟机磁盘或改动正在运行的正式实例。
