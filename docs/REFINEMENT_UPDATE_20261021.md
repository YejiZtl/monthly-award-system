# 终审优化更新 0.7.1

本次依据更新2中的8项意见、新核算工作簿，以及备注收起和追加的要求完成。

1. 调整原因选填，仍保留修改记录。修复修改金额弹窗标题被挤成多行。
2. 终审表和会议数据编辑去掉权重，导出隐藏原权重列以保持模板公式坐标兼容。
3. 终审取消替换申报材料。申报记录的重新选材料按钮变灰；后端拒绝修订和同部门/同名项目替换，不能通过旧页面绕过。
4. 介绍人改为引进人。
5. 每行备注默认一行摘要，点击展开；可修改已有备注或追加会议记录，点击保存后收起。每个项目独立保存，最终两种导出均包含备注。历史统一项目备注作为未单独编辑项目的默认值保留。
6. 使用原系统的中文无衬线字体，导航16px、表格和常用按钮15px；会议修改列固定在表格右侧。
7. 进入终审后材料锁定，原文件和历史导出保留。修改金额及备注仍可进行，已确认终审的内容修改后需要重新确认。
8. 使用新工作簿生成全部9种空白模板，增加Q声入浙心，按上传的短视频奖励合计核算并放入固定第17行（Excel第19行）；项目顺延。现象级奖公式按用户确认保留0元。系统仍不自行执行上传Excel公式，公式结果无缓存时须人工核对。

## 公司 Mac 更新命令

把“员工月奖系统_终审优化更新包_0.7.1_20261021.zip”复制到Mac桌面。在无人提交的时段更新，建议先做虚拟机快照。打开Mac终端粘贴：

```bash
scp "$HOME/Desktop/员工月奖系统_终审优化更新包_0.7.1_20261021.zip" awardadmin@<SERVER_IP>:~/monthly-award-refinement.zip
ssh -t awardadmin@<SERVER_IP> 'set -e; stage=$(mktemp -d "$HOME/monthly-award-refinement.XXXXXX"); /opt/monthly-award/.venv/bin/python -m zipfile -e "$HOME/monthly-award-refinement.zip" "$stage"; cd "$stage/员工月奖系统"; sudo bash infra/upgrade_vm_refinement_20261021.sh'
```

更新时自动备份程序、配置和数据库，保留账号、材料、历史文件和网络设置。备份位于 /var/backups/monthly-award/refinement-20261021-时间。更新失败恢复代码配置；产生新业务数据后不要直接恢复旧数据库。

验证：
```bash
ssh awardadmin@<SERVER_IP> 'curl -fsS http://127.0.0.1:8000/health'
```
应显示版本0.7.1、status为ok。浏览器按Command+Shift+R强制刷新，再检查终审备注展开保存、修改原因选填、材料锁定、Q模板下载。新申报请重新下载对应空白模板，已有申报和归档不会被新版模板覆盖。
